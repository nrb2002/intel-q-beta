# Milestone 04 — Customer Ticket Issuing

## Objective
Build the complete public customer workflow for obtaining a queue ticket without account creation.

## Customer Flow
Welcome → Services → Select Service → Enter First Name → Generate Ticket → Print/Download

## Tasks
- [ ] Build customer Welcome Page.
- [ ] Add clear link to `/services`.
- [ ] Add QR code pointing to the Services Page.
- [ ] Build public Services Page.
- [ ] Display active services dynamically.
- [ ] Let customer select a service.
- [ ] Require at least a first name.
- [ ] Validate first name client-side.
- [ ] Validate first name server-side.
- [ ] Generate ticket server-side.
- [ ] Generate human-readable ticket number.
- [ ] Prevent customers from submitting arbitrary ticket numbers/statuses.
- [ ] Display ticket after successful creation.
- [ ] Support browser printing.
- [ ] Support mobile ticket download where practical.
- [ ] Make the workflow usable on a friend's phone and kiosk/iPad.
- [ ] Avoid exposing unnecessary personal information.

## Ticket Example
```text
INTEL-Q
Immigrant Visas
Intake

Ticket
IV-042

Applicant
John
```

## Acceptance Criteria
- [ ] No login is required.
- [ ] A first name is required.
- [ ] Only active services can issue tickets.
- [ ] Ticket numbers are generated by the server.
- [ ] Concurrent requests cannot create duplicate ticket numbers.
- [ ] Ticket can be printed.
- [ ] Ticket can be downloaded/displayed on mobile.
- [ ] QR code correctly opens the public Services Page.

## Deliverables
- Customer Welcome Page.
- Public Services Page.
- Ticket creation API.
- Ticket confirmation/print view.
